# Mohamed Wael — React Portfolio

A professional, responsive portfolio website built with React + Vite.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Contact form setup

The contact form uses FormSubmit to send messages directly to `mwael3834@gmail.com`, so no backend, database, or environment variables are required.

On the first submission, FormSubmit sends a confirmation email to the recipient address. Confirm it once, then future submissions will be delivered automatically.

## Customize

Edit `src/main.jsx` to update:
- Email address
- About text
- Projects
- GitHub / LinkedIn links
- Skills

Edit `src/styles.css` to change the visual design.
